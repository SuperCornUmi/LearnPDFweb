Row Vectors and Column Vectors
• If A is an m × n matrix, each row of A is an n-tuple of real numbers and hence 
can be considered as a vector in ℝ¹×ⁿ. The m vectors corresponding to the rows 
of A will be referred to as the row vectors of A.
• Similarly, each column of A can be considered as a vector in ℝᵐ, and we can 
associate n column vectors with the matrix A.
CE2005 Linear Algebra: Coordinates, Rank, and Linear Transformations Chia-Ru Chung (NCU CSIE) 35


=== PDF PAGE 36 ===
Row Space and Column Space
If A is an m × n matrix, the subspace of ℝ¹×ⁿ spanned by the row vectors of A is 
called the row space of A. The subspace of ℝᵐ spanned by the column vectors of A 
is called the column space of A. 
- The row space contains linear combinations of rows. 
- The column space contains linear combinations of columns. 
- Their vectors generally belong to different spaces.

=== PDF PAGE 38 ===
Theorem 3.6.1: Row Equivalent Matrices
Two row equivalent matrices have the same row space.
CE2005 Linear Algebra: Coordinates, Rank, and Linear Transformations Chia-Ru Chung (NCU CSIE) 38
Proof:
If B is row equivalent to A, then B can be formed from A by a finite sequence of
row operations. Every row of B is therefore a linear combination of the rows of A.
Consequently, every linear combination of rows of B is also a linear combination of rows 
of A. The row space of B is a subspace of the row space of A. Every elementary row 
operation is reversible. Thus, A is row equivalent to B, and every row of A is a linear 
combination of the rows of B. The row space of A is therefore a subspace of the row space 
of B. Each row space contains the other, so the two row spaces are equal. This result 
explains why row reduction can identify a basis for the original row space.

=== PDF PAGE 39 ===
Rank and a Basis for the Row Space
Definition: 
The rank of a matrix A, denoted rank(A), is the dimension of the row space of A.
• To determine the rank of a matrix, we can reduce the matrix to row echelon form. 
The nonzero rows of the row echelon matrix will form a basis for the row space.
• By Theorem 3.6.1, this is also a basis for the row space of A. The rank equals the 
number of nonzero rows in its row echelon form.
CE2005 Linear Algebra: Coordinates, Rank, and Linear Transformations Chia-Ru Chung (NCU CSIE) 39

=== PDF PAGE 40 ===
Why the Nonzero Echelon Rows Form a Basis
• The nonzero rows span the row space because adding or removing zero rows 
does not change any linear combination.
• They are linearly independent. In a zero linear combination of the nonzero rows, 
the first leading column forces the coefficient of the first row to be zero. The 
next leading column forces the coefficient of the second row to be zero.
• Continuing through all leading columns forces every coefficient to be zero. 
Thus, the nonzero rows form a basis.

Theorem 3.6.2: Consistency Theorem for Linear 
Systems
A linear system Ax = b is consistent if and only if b is in the column space of A.
Proof: 
If Ax = b is consistent, a solution gives coefficients x₁, …, xₙ with b = x₁a₁ + 
⋯ + xₙaₙ. Hence, b is in the column space.
If b is in the column space, it has such an expression. The vector x = (x₁, …, 
xₙ)ᵀ then satisfies Ax = b, so the system is consistent.

Theorem 3.6.3: Existence and Uniqueness
Let A be an m × n matrix. The linear system Ax = b is consistent for every b ∈ ℝᵐ 
if and only if the column vectors of A span ℝᵐ. The system Ax = b has at most one 
solution for every b∈ ℝᵐ if and only if the column vectors of A are linearly 
independent.
• “At most one” allows either no solution or one solution. Existence for every b
requires the spanning condition in the first statement.

The Number of Columns and the Dimension
• Let A be an m × n matrix. Its n column vectors belong to ℝᵐ.
• If the column vectors span ℝᵐ, then n ≥ m, because no set of fewer than m 
vectors can span ℝᵐ.
• If the column vectors are linearly independent, then n ≤ m, because every set of 
more than m vectors in ℝᵐ is linearly dependent.
• Thus, if the column vectors of A form a basis for ℝᵐ, then n = m.
CE2005 Linear Algebra: Coordinates, Rank, and Linear Transformations Chia-Ru Chung (NCU CSIE) 48

Corollary 3.6.4: Nonsingularity and a Column Basis
An n × n matrix A is nonsingular if and only if the column vectors of A form a basis for 
ℝⁿ.
Proof: 
If A is nonsingular, Ax = 0 has only the trivial solution. Therefore, its n columns
are linearly independent and form a basis for ℝⁿ.
Conversely, if the columns form a basis, they are linearly independent. Thus, Ax = 
0 has only the trivial solution. Since A is square, A is nonsingular.

Similar Matrices
Let A and B be two n  n matrices. B is said to be similar to A if there exists a 
nonsingular matrix S such that B = S–1AS.
• Similarity is symmetric. Multiplying on the left by S and on the right by S⁻¹ 
gives A = SBS–1 = (S –1)–1B(S–1)
• Thus, A is similar to B, and we may simply say that A and B are similar matrices.

Why a Simpler Representation Is Useful
• In Example 2, L is represented by a diagonal matrix D in the basis {y₁, y₂, y₃}.
• Multiplication by D acts separately on the three coordinates.
• It is easier to compute Dx and Dⁿx than to repeatedly multiply by the original 
matrix A. A suitable basis makes the action of the operator easier to understand.
