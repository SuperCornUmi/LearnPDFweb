From Spanning Sets to Linear Independence
• In this section, we look more closely at the structure of vector spaces. We consider 
only finite generating sets.
• A generating set is a spanning set.
• Each vector in the vector space can be built up from its elements using addition and 
scalar multiplication.
• A minimal spanning set has no unnecessary elements: all its elements are needed to 
span the vector space.
• We must therefore examine how its vectors depend on each other. This connects 
spanning sets from Section 3.2 to linear dependence and independence.

Reducing a Linear Combination
• Any linear combination of x₁, x₂, and x₃ reduces to a linear combination of x₁ and x₂:
α₁x₁ + α₂x₂ + α₃x₃
= α₁x₁ + α₂x₂ + α₃(3x₁ + 2x₂)
= (α₁ + 3α₃)x₁ + (α₂ + 2α₃)x₂.
• Thus, S = Span(x₁, x₂, x₃) = Span(x₁, x₂).
• Every combination of the three vectors is a combination of the first two. 
Conversely, a combination of x₁ and x₂ is a combination of all three with coefficient 
0 on x₃.

The Dependency Relation
• The relation x₃ = 3x₁ + 2x₂ can be written as
3x₁ + 2x₂ − x₃ = 0.
• All three coefficients in this relation are nonzero, so
x₁ = −(2/3)x₂ + (1/3)x₃,
x₂ = −(3/2)x₁ + (1/2)x₃,
x₃ = 3x₁ + 2x₂.
Span(x₁, x₂, x₃) = Span(x₁, x₂) = Span(x₁, x₃) = Span(x₂, x₃).
Any two of these three vectors span the same subspace S.

=== PDF PAGE 9 ===
No Dependency Relation for the First Two Vectors
• Suppose c₁x₁ + c₂x₂ = 0, where c₁ and c₂ are not both 0.
If c₁ ≠ 0, then x₁ = −(c₂/c₁)x₂.
If c₂ ≠ 0, then x₂ = −(c₁/c₂)x₁.
• Either possibility makes one vector a multiple of the other.
• But the entries of x₁ and x₂ show this is impossible:
the first entries would require the multiple −1/2,
whereas the second entries would require −1/3.
• Therefore, c₁x₁ + c₂x₂ = 0 implies c₁ = c₂ = 0.
• Span(x₁) and Span(x₂) are both proper subspaces of Span(x₁, x₂); both vectors are 
needed.

=== PDF PAGE 10 ===
Two Observations about Spanning Sets
(I) If v₁, v₂, …, vₙ span a vector space V and one of these vectors can be written 
as a linear combination of the other n − 1 vectors, then those n − 1 vectors 
span V .
(II) Given n vectors v₁, …, vₙ, it is possible to write one of the vectors as a linear 
combination of the other n − 1 vectors if and only if there exist scalars c₁, …, 
cₙ, not all zero, such that c₁v₁ + c₂v₂ + · · ·  + cₙvₙ = 0.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 10
The first observation concerns the span. 
The second expresses a dependency using a zero linear combination.

=== PDF PAGE 11 ===
Proof of Observation (I)
Suppose vₙ is a linear combination of the other vectors:
vₙ = β₁v₁ + β₂v₂ + ⋯ + βₙ₋₁vₙ₋₁.
Let v be any element of V . Because v₁, …, vₙ span V ,
v = α₁v₁ + α₂v₂ + ⋯ + αₙ₋₁vₙ₋₁ + αₙvₙ.
Substitute the expression for vₙ into this combination:
v = α₁v₁ + α₂v₂ + ⋯ + αₙ₋₁vₙ₋₁ + αₙ(β₁v₁ + β₂v₂ + ⋯ + βₙ₋₁vₙ₋₁).
Distributing αₙ and collecting coefficients removes vₙ from the representation 
without changing the vector v.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 11

=== PDF PAGE 12 ===
Completing the Proof of Observation (I)
Collecting the coefficients from the substitution gives
v = (α₁ + αₙβ₁)v₁ + (α₂ + αₙβ₂)v₂ + ⋯ + (αₙ₋₁ + αₙβₙ₋₁)vₙ₋₁.
This is a linear combination of v₁, …, vₙ₋₁.
The vector v was an arbitrary element of V , so every vector in V can be written 
using these n − 1 vectors.
Hence, v₁, …, vₙ₋₁ span V .
Deleting a vector already in the span of the others does not change the vector 
space that they span.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 12

=== PDF PAGE 13 ===
Proof of Observation (II)
First suppose one vector, say vₙ, is a linear combination of the others:
vₙ = α₁v₁ + α₂v₂ + ⋯ + αₙ₋₁vₙ₋₁.
Subtract vₙ from both sides: α₁v₁ + α₂v₂ + ⋯ + αₙ₋₁vₙ₋₁ − vₙ = 0.
Set cᵢ = αᵢ for i = 1, …, n − 1 and cₙ = −1.
Then c₁v₁ + c₂v₂ + ⋯ + cₙvₙ = 0.
These coefficients are not all zero because cₙ = −1.
Thus, a vector expressed using the others produces a nonzero choice of 
coefficients giving the zero vector.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 13

=== PDF PAGE 14 ===
The Converse in Observation (II)
Conversely, suppose c₁v₁ + c₂v₂ + ⋯ + cₙvₙ = 0 and at least one of the coefficients, say cₙ, 
is nonzero.
Move the other terms to the right-hand side:
cₙvₙ = −c₁v₁ − c₂v₂ − ⋯ − cₙ₋₁vₙ₋₁.
Because cₙ ≠ 0, divide by cₙ:
vₙ = (−c₁/cₙ)v₁ + (−c₂/cₙ)v₂ + ⋯ + (−cₙ₋₁/cₙ)vₙ₋₁.
This writes vₙ as a linear combination of the others.
Both directions are established. 
The condition “not all zero” is what permits this division.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 14

=== PDF PAGE 15 ===
Linear Independence
• Definition: 
The vectors v₁, v₂, …, vₙ in a vector space V are said to be linearly independent 
if c₁v₁ + c₂v₂ + ··· + cₙvₙ = 0 implies that all the scalars c₁, …, cₙ must equal 0.
• Observation (II) shows that none of these vectors can be written as a linear 
combination of the others.
• To verify independence, we must consider every possible choice of coefficients 
giving the zero vector and show that all those coefficients must be zero.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 15

=== PDF PAGE 16 ===
Linear Independence and Minimal Spanning Sets
• If {v₁, v₂, …, vₙ} is a minimal spanning set, then v₁, v₂, …, vₙ are linearly independent. 
Otherwise, Observation (II) would express one vector using the others, and 
Observation (I) would let us delete it while still spanning V , contradicting minimality.
• Conversely, if v₁, …, vₙ are linearly independent and span V , then {v₁, …, vₙ} is a 
minimal spanning set. If one vector could be removed without changing the span, it 
would be a combination of the others, contradicting Observation (II) and independence.
• A minimal spanning set is called a basis.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 16

Linear Dependence
• Definition:
The vectors v₁, v₂, …, vₙ in a vector space V are said to be linearly dependent if 
there exist scalars c₁, c₂, …, cₙ, not all zero, such that c₁v₁ + c₂v₂ + ··· + cₙvₙ = 0.
• Unlike independence, dependence is established by finding one choice of 
coefficients that are not all zero. Observation (II) then shows that at least one 
vector can be written as a linear combination of the others.
• The next example gives such a choice explicitly.

=== PDF PAGE 20 ===
Trivial and Nontrivial Choices of Scalars
• For any set {v₁, v₂, …, vₙ} in a vector space V , c₁v₁ + c₂v₂ + ⋯ + cₙvₙ = 0 always 
holds when c₁ = c₂ = ⋯ = cₙ = 0. This is the trivial choice of scalars.
• If there are nontrivial choices of scalars for which c₁v₁ + ⋯ + cₙvₙ equals the 
zero vector, then v₁, …, vₙ are linearly dependent.
• If the only way this combination can equal the zero vector is for all the scalars 
c₁, …, cₙ to be 0, then v₁, …, vₙ are linearly independent.
• “Nontrivial” means at least one coefficient is nonzero.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 20

Example 3  Independence in ℝ³

(a) (1, 1, 1)ᵀ, (1, 1, 0)ᵀ, (1, 0, 0)ᵀ

• The number of vectors need not equal the number of entries.

Example 3(a)  Only the Trivial Solution
We must show that
c₁(1, 1, 1)ᵀ + c₂(1, 1, 0)ᵀ + c₃(1, 0, 0)ᵀ = (0, 0, 0)ᵀ 
is possible only if the scalars c₁, c₂, c₃ are all zero.
Equating the three entries gives
c₁ + c₂ + c₃ = 0
c₁ + c₂ = 0
c₁ = 0
The third equation gives c₁ = 0; the second then gives c₂ = 0; the first then gives c₃ = 0.
The only solution is c₁ = c₂ = c₃ = 0.
Therefore, the three vectors are linearly independent.

=== PDF PAGE 28 ===
Example 3(b)  Two Independent Vectors
If
c₁(1, 0, 1)ᵀ + c₂(0, 1, 0)ᵀ = (0, 0, 0)ᵀ,
then
(c₁, c₂, c₁)ᵀ = (0, 0, 0)ᵀ.
Equality of the entries gives c₁ = 0 and c₂ = 0.
The third entry repeats the condition c₁ = 0.
Therefore, the two vectors are linearly independent.
There are three entry equations but only two coefficients.
Independence requires that every coefficient be zero.

Example 3(c)  A Singular Coefficient Matrix

Theorem 3.3.1  Dependence and Singularity
Let x₁, x₂, …, xₙ be n vectors in ℝⁿ and let X = (x₁, …, xₙ). The vectors x₁, x₂, …, 
xₙ will be linearly dependent if and only if X is singular (i.e., det(X) = 0).
• Here X is the n × n matrix whose columns are the vectors.
• Example 3(a) has a nonsingular coefficient matrix;
• Example 3(c) has a singular coefficient matrix.
• The theorem explains both conclusions through the same test.
• Its hypothesis is n vectors in ℝⁿ, so X must be square.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 31

=== PDF PAGE 32 ===
Theorem 3.3.1  Proof
The equation c₁x₁ + c₂x₂ + ··· + cₙxₙ = 0
can be rewritten as a matrix equation:
 c1 x11 + c2 x12 + … + cn x1n = 0
c1 x21 + c2 x22 + … + cn x2n = 0

c1 xn1 + c2 xn2 + … + cn xnn = 0
Let c = (c1, c2, …, cn)T, then the system can be written as Xc = 0
c has a nontrivial solution iff X is singular
 x1, x2, …, xn will be linearly dependent iff X is singular.

Testing n Vectors in ℝⁿ Using a Determinant
• Form a matrix X whose columns are the vectors being tested.
• Calculate det(X) to determine whether X is singular.
If det(X) = 0, X is singular and the vectors are linearly dependent.
If det(X) ≠ 0, X is nonsingular and the vectors are linearly independent.
• Theorem 3.3.1 connects this determinant calculation to the existence of 
nontrivial solutions of Xc = 0.
• The determinant test applies to the square matrix formed from n vectors in ℝⁿ.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 33

Testing k Vectors in ℝⁿ
• To test vectors x₁, x₂, …, xₖ in ℝⁿ, rewrite c₁x₁ + c₂x₂ + ··· + cₖxₖ = 0 as Xc = 0, where 
X = (x₁, x₂, …, xₖ).
• If k ≠ n, then X is not square, so determinants cannot be used to decide whether the 
vectors are independent.
• The homogeneous system always has the trivial solution c = 0.
• Its row echelon form has free variables if and only if there are nontrivial solutions; the 
vectors are then dependent.
• If there are no free variables, c = 0 is the only solution, and the vectors are linearly 
independent.
• Thus, elimination provides a test even when X is rectangular.
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 36

Theorem 3.3.2  Unique Linear Combinations
Let v₁, …, vₙ be vectors in a vector space V . A vector v in Span(v₁, …, vₙ) can be 
written uniquely as a linear combination of v₁, …, vₙ if and only if v₁, …, vₙ are 
linearly independent.
• Membership in the span guarantees that a representation exists.
• Independence guarantees that its coefficients are unique.
• If the vectors are dependent, a linear combination with coefficients not all zero equals zero. 
Adding it changes the coefficients without changing v.

Theorem 3.3.2  Setting Up the Proof
If v ∈ Span(v₁, …, vₙ), then v = α₁v₁ + α₂v₂ + ··· + αₙvₙ. (5)
Suppose that v can also be expressed as v = β₁v₁ + β₂v₂ + ··· + βₙvₙ. (6)
We will show that, if v₁, …, vₙ are linearly independent, then βᵢ = αᵢ for i = 1, …, n.
If v₁, …, vₙ are linearly dependent, it is possible to choose the βᵢ’s different from 
the αᵢ’s.
Both equations represent the same vector v; the question is whether their 
coefficients must agree.

Theorem 3.3.2  Independence Gives Uniqueness
Assume that v₁, …, vₙ are linearly independent.
Subtracting (6) from (5) yields (α₁ − β₁)v₁ + (α₂ − β₂)v₂ + ··· + (αₙ − βₙ)vₙ = 0.   (7)
By linear independence, all coefficients in (7) must be zero:
α₁ − β₁ = 0, α₂ − β₂ = 0, …, αₙ − βₙ = 0.
Hence, α₁ = β₁, α₂ = β₂, …, αₙ = βₙ.
Thus, representation (5) is unique when v₁, …, vₙ are linearly independent.
Any two representations have identical coefficients; therefore, no different 
representation is possible.

Theorem 3.3.2  Dependence Changes the Coefficients
If v₁, …, vₙ are linearly dependent, there exist c₁, …, cₙ, not all zero, such that
0 = c₁v₁ + c₂v₂ + ··· + cₙvₙ. (8)
Set β₁ = α₁ + c₁, β₂ = α₂ + c₂, …, βₙ = αₙ + cₙ.
Adding (5) and (8) gives
v = (α₁ + c₁)v₁ + (α₂ + c₂)v₂ + ··· + (αₙ + cₙ)vₙ
= β₁v₁ + β₂v₂ + ··· + βₙvₙ.
Adding a combination equal to zero leaves v unchanged, while the coefficients 
may change.

Dimension
Definition
Let V be vector space. If V has a basis consisting of n vectors, we say that V has 
dimension n. The subspace {0} of V is said to have dimension 0. V is said to be finite-
dimensional if there is a finite set of vectors that spans V; otherwise we say that V is 
infinite-dimensional.
- The notation dim V gives the number of vectors in any basis.
- The two bases in Example 1 each contain three vectors, so dim ℝ³  = 3. Example 2 gives dim 
ℝ2×2 = 4.
- The basis for N(A) above has two vectors, so dim N(A) = 2.
- Dimension counts basis elements, including when the elements are matrices rather than 
column vectors.

Theorem 3.4.3
If V is a vector space of dimension n > 0, then
(I) any set of n linearly independent vectors spans V .
(II) any n vectors that span V are linearly independent.
- A basis requires both independence and spanning. Once dim V = n is known and a set has 
exactly n vectors, this theorem shows that verifying either condition is enough.
- Part (I) supplies spanning from independence; part (II) supplies independence from 
spanning.
- We prove each statement using the limit on independent sets established in Theorem 3.4.1.

Proof of Theorem 3.4.3 Part II
Suppose v₁, …, vₙ span V . If they were linearly dependent, one vector, say vₙ, could be

Theorem 3.4.4
If V is a vector space of dimension n > 0, then
(i) no set of fewer than n vectors can span V .
(ii) any subset of fewer than n linearly independent vectors can be extended to 
form a basis for V .
(iii) any spanning set containing more than n vectors can be pared down to form a 
basis for V .
CE2005 Linear Algebra: Linear Independence and Bases Chia-Ru Chung (NCU CSIE) 82

Proof of Theorem 3.4.4 Part i
A basis for V consists of n linearly independent vectors.
Suppose a set of k vectors, where k < n, spanned V .
Theorem 3.4.1 would then make every collection of more than k vectors in V linearly 
dependent.
In particular, the n basis vectors would be dependent, because n > k. This contradicts the 
definition of a basis.
Therefore, no set of fewer than n vectors can span V .
This is the same spanning-set argument used in
Theorem 3.4.3(I). It explains why an independent set with fewer than n vectors still 
needs additional vectors to span V .

Proof of Theorem 3.4.4 Part ii
Suppose v₁, …, vₖ are linearly independent and k < n.
By part (i), Span(v₁, …, vₖ) is a proper subspace of V .
Choose vₖ₊₁ in V but not in Span(v₁, …, vₖ).

Thus, the original independent set has been extended to form a basis for V .

Proof of Theorem 3.4.4 Part iii
Suppose v₁, …, vₘ span V and m > n.
By Theorem 3.4.1, these vectors are linearly dependent.
One vector, say vₘ, is a linear combination of the others.
Eliminate vₘ. The remaining m − 1 vectors still span V, because every occurrence of vₘ 
can be replaced by that linear combination.
If m − 1 > n, eliminate another dependent vector.
Continue until a spanning set with n vectors remains.
By Theorem 3.4.3(II), these n vectors are linearly independent. 
The remaining set is therefore a basis for V.
This gives a basis by paring down the original spanning set.

Standard Bases
• The standard basis for ℝⁿ is {e₁, e₂, …, eₙ}.
• The standard basis for ℝ2×2 is {E₁₁, E₁₂, E₂₁, E₂₂}.
• The standard basis for Pₙ is {1, x, x², x³, …, xⁿ⁻¹}.
• Recall that Pₙ consists of polynomials of degree less than n, together with the zero 
polynomial. Its standard basis has n elements, so dim Pₙ = n. This differs from P, the 
space of all polynomials, which is infinite dimensional.
• Standard bases are the most natural ones for representing vectors, matrices, and 
polynomials. Other bases may be more appropriate for applied problems.
