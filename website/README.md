# 知識課堂：本機閱讀網站

後續新增課程及章節，依 [統一製作標準 v1.0](../wiki/standards/PDF課程教材製作標準.md) 執行。網站目前只有 Lecture 5 的資料與專用路由；新增單元時須擴充資料載入、路由、課程／章節卡片、資產及下載連結，保留舊單元。頁數、投影片數量、來源路徑與最近閱讀位置須按單元區分，不將 87 頁／15 張當通用設定。

直接以瀏覽器開啟 `index.html`，不需安裝或連網。主要功能使用相鄰的 CSS、JavaScript 與本地影像；請勿只移動 index.html。

入口順序：所有課程 → 線性代數 → Lecture 5。章節內可以切換逐頁講解、簡報、完整筆記、圖解與文獻。

- 逐頁講解：87 頁成對排列成連續長條，在獨立閱讀區捲動，外層網頁不會跟著捲動；頁碼選單同步顯示目前位置，可跳至指定頁，也可用左右鍵換頁。搜尋目錄預設收起，可隨時展開，並保存最近閱讀頁碼。
- 原頁對照：桌面版使用全寬閱讀版面，原頁約占主要閱讀區六成寬，右側為講解。手機以原頁在上、講解在下排列。第 1 頁改用不含教師姓名的自製 SVG 封面，仍保留原頁對應位置；原始文件及來源記錄不修改。
- 簡報：15 張、每張講解稿、全螢幕、鍵盤切換，另可下載 Markdown 內容與講稿。換張只更新簡報內容，保留捲動位置及按鈕位置。
- 筆記：87 頁連續閱讀、Markdown 原文切換、下載及列印。
- 圖解：觀念鏈、判定流程、定理條件表及二維向量夾角互動。

原 PDF 與 Wiki 連結指向上一層專案資料夾；搬移時請保留原專案的 raw/、wiki/、notes/ 等相對位置。網站不是雲端服務，沒有上傳文件，也不會自動同步 Wiki；教材變更後需重新生成。

外部參考文獻需連網開啟，其內容不是離線資產。若作業系統不允許直接預覽 HTML，可在專案根目錄用本機靜態 HTTP 服務開啟 website/index.html。
