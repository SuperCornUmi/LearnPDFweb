# 知識課堂：本機閱讀網站

後續新增課程及章節，依 [統一製作標準 v1.1](../wiki/standards/PDF課程教材製作標準.md) 執行。網站目前包含 Lecture 5、6，以 `window.LESSONS` 註冊獨立單元；新增單元建立教材及 `config.json`，生成資料腳本並加入根目錄 HTML，課程／章節卡片由資料建立，保留舊單元。頁數、投影片數量、來源路徑與最近閱讀位置須按單元區分，不將 87 頁／15 張當通用設定。

直接以瀏覽器開啟專案根目錄的 [index.html](../index.html)，不需安裝或連網。CSS、JavaScript、教材資料、下載與影像保留在 `website/`；搬移時保留整個專案的相對結構。

入口順序：所有課程 → 線性代數 → Lecture 5 或 Lecture 6。章節內可以切換逐頁講解、簡報、完整筆記、圖解與文獻。

- 內容品質：翻譯保留原頁實質資訊；講解交代計算／推理過程與結果意義，必要時分步；補充緊扣當頁且可省略，無內容就不顯示空卡片。長文字沿既有閱讀區閱讀，不裁切或縮成難讀字體。
- 逐頁講解：依單元的 87／152 頁成對排列成連續長條，在獨立閱讀區捲動，外層網頁不會跟著捲動；頁碼選單同步顯示目前位置，可跳至指定頁，也可用左右鍵換頁。搜尋目錄預設收起，可隨時展開，並保存最近閱讀頁碼。
- 專注閱讀：逐頁模式預設收起上方標頭、課程說明與模式列，只留精簡工具列，增加原頁可見高度。按「展開導覽」可切換模式、返回課程或下載筆記；再按「收起上方」繼續閱讀。會記住選擇，切換時保留目前頁面位置。
- 原頁對照：桌面版使用全寬閱讀版面，原頁約占主要閱讀區六成寬，右側為講解。手機以原頁在上、講解在下排列。第 1 頁改用不含教師姓名的自製 SVG 封面，仍保留原頁對應位置；原始文件及來源記錄不修改。
- 簡報：Lecture 5 為 15 張、Lecture 6 為 20 張，均有每張講解稿、全螢幕、鍵盤切換，另可下載 Markdown 內容與講稿。換張只更新簡報內容，保留捲動位置及按鈕位置。
- 筆記：依單元全部頁面連續閱讀、Markdown 原文切換、下載及列印。
- 圖解：觀念鏈、判定流程、定理條件表及二維向量夾角互動；Lecture 6 另有換基底流程、相似交換圖與幾何轉換互動。

網頁內的資產、原 PDF 與 Wiki 連結，以根目錄 `index.html` 為基準；搬移時保留 raw/、wiki/、notes/、website/ 等相對位置。此版本已準備好供 GitHub Pages 發布，尚未代為上傳或部署，也不會自動同步 Wiki；教材變更後需重新生成。

GitHub Pages 的發布來源使用 repository 根目錄；根目錄 `.nojekyll` 讓本專案按靜態檔案提供。路徑不用站台開頭的 `/`，支援 `https://帳號.github.io/Repository名稱/` 的專案子路徑。

外部參考文獻需連網開啟，其內容不是離線資產。若作業系統不允許直接預覽 HTML，可在專案根目錄用本機靜態 HTTP 服務開啟 index.html。
