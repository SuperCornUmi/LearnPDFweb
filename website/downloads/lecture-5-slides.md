## 1. 從「有沒有冗餘」到基底

- 線性獨立與基底
- CE2005 · Lecture 5
- 生成 → 獨立 → 唯一表示 → 基底 → 維度

來源：CE2005 PDF pp. 1–5；詳細說明見 notes 對應頁段。

## 2. 一個向量，可能沒有帶來新方向

- x₃=3x₁+2x₂
- Span(x₁,x₂,x₃)=Span(x₁,x₂)
- 刪掉可由其他表示的向量，不改變 span

來源：CE2005 PDF pp. 6–14；詳細說明見 notes 對應頁段。

## 3. 獨立與相依：差在係數

- Σcᵢvᵢ=0
- 只有 c=0 → 獨立
- 存在 c≠0 → 相依
- 非平凡＝至少一個係數非零

來源：CE2005 PDF pp. 15–20、34；詳細說明見 notes 對應頁段。

## 4. 把幾何變成判斷

- 兩個獨立向量 → 過原點的平面
- 第三向量在平面內 → 相依
- 第三向量在平面外 → 獨立

來源：CE2005 PDF pp. 21–24；詳細說明見 notes 對應頁段。

## 5. 通用方法：解 Xc=0

- 待測向量排成矩陣的欄
- 有自由變數 → 相依
- 每個係數欄都有主元 → 獨立

來源：CE2005 PDF pp. 26–30、36–39；詳細說明見 notes 對應頁段。

## 6. 行列式是方陣的捷徑

- n 個 ℝⁿ 向量 → n×n 矩陣
- det(X)≠0 → 獨立
- det(X)=0 → 相依
- 矩形矩陣仍用消去法

來源：CE2005 PDF pp. 31–39；詳細說明見 notes 對應頁段。

## 7. 能表示，不等於表示唯一

- 屬於 span → 表示存在
- 獨立 → 係數唯一
- 相依 → α 與 α+c 表示同一向量

來源：CE2005 PDF pp. 40–44；詳細說明見 notes 對應頁段。

## 8. 多項式也能變成向量問題

- 固定次方順序，比較係數
- Σcᵢpᵢ=0 → 齊次線性系統
- 例題：3p₁−2p₂+p₃=0

來源：CE2005 PDF pp. 46–50；詳細說明見 notes 對應頁段。

## 9. Wronskian：有方向的判準

- 各欄放函數，各列放導數
- 某點 W≠0 → 函數獨立
- W≡0 → 一般無法判定
- 前提：具有所需連續導數

來源：CE2005 PDF pp. 51–57；詳細說明見 notes 對應頁段。

## 10. 反例比口訣更重要

- f=x²，g=x|x|，區間 [−1,1]
- W[f,g]≡0
- 代 x=±1，仍迫使 c₁=c₂=0
- 所以函數獨立

來源：CE2005 PDF pp. 58–61；詳細說明見 notes 對應頁段。

## 11. 基底：夠用，而且沒有冗餘

- 基底＝線性獨立＋生成整個 V
- 每個向量都有唯一表示
- 矩陣、多項式也有基底

來源：CE2005 PDF pp. 63–67、86；詳細說明見 notes 對應頁段。

## 12. 從自由參數讀出零空間基底

- x=α(1,−2,1,0)ᵀ+β(−1,1,0,1)ᵀ
- 兩向量生成所有解
- 第三、四分量證明獨立
- dim N(A)=2

來源：CE2005 PDF pp. 68–70、75；詳細說明見 notes 對應頁段。

## 13. 維度讓基底驗證變簡單

- 所有基底大小相同
- 已知 dim V=n，且恰有 n 個向量
- 獨立或生成，驗一項即可
- 本講義 dim Pₙ=n

來源：CE2005 PDF pp. 71–81、86；詳細說明見 notes 對應頁段。

## 14. 擴充與縮減：兩條到基底的路

- 不足 n 個的獨立集 → 加入 span 外向量
- 超過 n 個的生成集 → 刪去冗餘向量
- 每一步保留原有性質

來源：CE2005 PDF pp. 82–85；詳細說明見 notes 對應頁段。
