# Lecture 5 教材來源

此單元是第一份實作參考；後續教材以 [統一製作標準 v1.1](../../../wiki/standards/PDF課程教材製作標準.md) 為準，使用 `templates/` 的通用範本。此處的 87 頁、15 張與來源路徑僅適用 Lecture 5，不應直接複製成其他單元的固定值。

- `pages.txt`：87 列，每列為「標題｜中文翻譯｜觀念講解｜教學補充」；按 PDF 頁序排列，勿刪除空白用途的頁面。
- `slides.txt`：15 張精簡簡報，每列為「標題｜以分號分隔的重點｜講解稿｜PDF 頁碼」。
- `build.py`：由同一份內容生成 Markdown 筆記、簡報、講稿、JSON 與網站資料。
- `manifest.json`：記錄這次製作採用的 Wiki、PDF、教材原稿雜湊，供後續比對更新。

修改教材時先改 pages.txt／slides.txt，再使用環境中的 Python 執行 build.py。原始頁面影像位於 website/assets/lecture5/，源自保存的 PDF；原始 PDF 不修改。

日期：2026-11-03。中文為忠實意譯；重複頁尾資訊未逐頁複製。公式以 Unicode 與逐列矩陣表示，無需網路字型或數學排版 CDN。

## 後續內容修訂規則

依[統一標準 v1.1](../../../wiki/standards/PDF課程教材製作標準.md)，每頁翻譯與講解必填；補充為選用，第四欄可以留空，仍保留最後的分隔符號。不能刪掉該頁整列。生成器及網頁在空值時省略補充標題／卡片。

翻譯逐項核對原頁，講解補出符號、步驟、理由與結果；補充只協助理解當頁，不重複或跳太遠。重建後同步 notes、網站資料及下載，檢查較長頁面的桌面／手機排版。若只改內容，不另動未指定的簡報、圖解或樣式。標準版本由生成器讀取統一標準；原交付版本保留於歷史紀錄，重新審閱時再記錄本次實際版本與驗收。
