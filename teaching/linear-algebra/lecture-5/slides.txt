從「有沒有冗餘」到基底｜線性獨立與基底;CE2005 · Lecture 5;生成 → 獨立 → 唯一表示 → 基底 → 維度｜本講的核心不是記住更多名詞，而是分清「能否表示」「有無冗餘」「表示是否唯一」。先展示知識主線，再說明本簡報濃縮重點，完整內容請切到逐頁講解。｜1–5
一個向量，可能沒有帶來新方向｜x₃=3x₁+2x₂;Span(x₁,x₂,x₃)=Span(x₁,x₂);刪掉可由其他表示的向量，不改變 span｜用講義的三個向量示範逐分量計算。再把一般線性組合中的 x₃ 代換掉，說明為何這不是只有某個特例成立，而是整個 span 相同。｜6–14
獨立與相依：差在係數｜Σcᵢvᵢ=0;只有 c=0 → 獨立;存在 c≠0 → 相依;非平凡＝至少一個係數非零｜提醒零組合一定有全零解，所以只找到全零解沒有證明力。獨立要排除其他解，相依則只要一組非平凡解。用第 34 頁係數包含零的例子釐清用語。｜15–20、34
把幾何變成判斷｜兩個獨立向量 → 過原點的平面;第三向量在平面內 → 相依;第三向量在平面外 → 獨立｜先固定 x、y 獨立的前提。讓讀者把 z 想成新加入的方向，再用「若相依就能解出 z 在 span 內」把圖像和反證法連起來。｜21–24
通用方法：解 Xc=0｜待測向量排成矩陣的欄;有自由變數 → 相依;每個係數欄都有主元 → 獨立｜先數向量個數，再數分量數。以 4×3 例題說明方程數與係數數量不同，真正要看的不是零列，而是有沒有自由係數。｜26–30、36–39
行列式是方陣的捷徑｜n 個 ℝⁿ 向量 → n×n 矩陣;det(X)≠0 → 獨立;det(X)=0 → 相依;矩形矩陣仍用消去法｜將定理的前提直接和演算法綁在一起。用例 5 的行列式零與明確零組合做兩種驗證，不要把行列式套到非方陣。｜31–39
能表示，不等於表示唯一｜屬於 span → 表示存在;獨立 → 係數唯一;相依 → α 與 α+c 表示同一向量｜先設兩份表示，相減後得到零組合。獨立讓差係數全零；相依則反過來利用非零的零組合製造另一份表示。這是後面基底座標的基礎。｜40–44
多項式也能變成向量問題｜固定次方順序，比較係數;Σcᵢpᵢ=0 → 齊次線性系統;例題：3p₁−2p₂+p₃=0｜將三個多項式按 x²、x、常數順序排成係數欄，再指回熟悉的 Xc=0。提醒等於零多項式是每個係數都為零，不是只在一點為零。｜46–50
Wronskian：有方向的判準｜各欄放函數，各列放導數;某點 W≠0 → 函數獨立;W≡0 → 一般無法判定;前提：具有所需連續導數｜先用兩函數公式 W=fg′−gf′。再從相依關係逐次微分，解釋相依必迫使 W 恆零，而定理採用逆否命題，沒有宣稱逆命題。｜51–57
反例比口訣更重要｜f=x²，g=x|x|，區間 [−1,1];W[f,g]≡0;代 x=±1，仍迫使 c₁=c₂=0;所以函數獨立｜完整走一次分段導數與兩點代入。強調區間不可省略，也不能把方陣行列式的雙向判準直接搬到函數 Wronskian。｜58–61
基底：夠用，而且沒有冗餘｜基底＝線性獨立＋生成整個 V;每個向量都有唯一表示;矩陣、多項式也有基底｜用兩個條件分別對應無冗餘與全覆蓋。以 2×2 矩陣的四個標準元素說明，基底元素不一定是一般數字欄。｜63–67、86
從自由參數讀出零空間基底｜x=α(1,−2,1,0)ᵀ+β(−1,1,0,1)ᵀ;兩向量生成所有解;第三、四分量證明獨立;dim N(A)=2｜先解系統，再拆開 α、β 項，最後補上獨立性驗證。不能只看到兩個參數向量，就跳過是否生成全部解的說明。｜68–70、75
維度讓基底驗證變簡單｜所有基底大小相同;已知 dim V=n，且恰有 n 個向量;獨立或生成，驗一項即可;本講義 dim Pₙ=n｜從兩組基底互相限制元素數的證明帶出維度。特別標明「已知維度」和「恰好 n 個」兩個前提，再用第 81 頁 det=2 的例子。｜71–81、86
擴充與縮減：兩條到基底的路｜不足 n 個的獨立集 → 加入 span 外向量;超過 n 個的生成集 → 刪去冗餘向量;每一步保留原有性質｜擴充保留獨立，縮減保留生成。不能隨意新增或刪除；新增位置與可刪係數都要有依據。兩條路最後都在 n 個元素時成為基底。｜82–85
用四個問題檢查理解｜零組合是否只有零解？;矩陣是否為方陣？;函數判準是否能反推？;維度及向量數是否已知？｜請讀者用自己的話回答，再帶回方法對照表。需要完整證明時回到逐頁講解，不把精簡簡報當成原講義的完整替代。｜15、31–36、56–60、78–86
