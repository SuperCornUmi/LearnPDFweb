# 矩陣子空間與秩零度

[索引](../index.md) · [線性代數](../topics/線性代數.md) · [來源 Lecture 6](../sources/src-20261103-ce2005-lecture-6.md)

本 Wiki 用 row（橫列）、column（直欄）避免中文地域用語差異。A 為 m×n，row space 的元素長 n，column space 的元素長 m。兩空間維度相同＝rank A，但集合不必相同。（PDF pp. 35–40、57–59）

| 問題 | 正確作法／判準 | 頁碼 |
| --- | --- | --- |
| row space 基底 | 階梯形的非零 rows | 38–41 |
| column space 基底 | 用主元欄編號，回原矩陣取欄 | 56–62 |
| N(A) 基底 | 解齊次系統，每次將一個自由變數設 1，其餘 0 | 50–55 |
| Ax=b 是否可解 | b∈Col(A) | 42–43 |
| 每個 b 是否都可解 | 欄生成 ℝᵐ | 45–46 |
| 每個 b 是否至多一解 | 欄獨立 | 45、47 |

rank A+dim N(A)=n，右側是輸入欄數。主元 r 個，自由變數 n−r 個；自由位置的單位模式證明所得解向量獨立。（pp. 50–55）

行運算保留齊次解與欄相依關係，但不一般保留欄空間。（p. 56）外部佐證的有限範圍見 [MIT 查證](../sources/web-20261104-mit-coordinates-spaces.md)，沒有以搜尋摘要作證。
