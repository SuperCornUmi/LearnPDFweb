# 基底與維度

[返回索引](../index.md) · [線性代數](../topics/線性代數.md) · [來源](../sources/src-20261103-ce2005-lecture-5.md)

## 定義

基底是同時線性獨立且生成整個 V 的集合，也就是沒有冗餘的最小生成集。同一有限維向量空間的所有基底元素數相同，這個數就是 `dim V`；零空間 `{0}` 的維度為 0。（[Lecture 5](../sources/src-20261103-ce2005-lecture-5.md)，PDF pp. 16、63、74–75）

## 已知 dim V = n > 0 的結果

| 向量組條件 | 可得結論 | 證據 |
| --- | --- | --- |
| 恰 n 個且獨立 | 自動生成 V，構成基底 | 同來源 PDF pp. 78–79 |
| 恰 n 個且生成 V | 自動獨立，構成基底 | 同來源 PDF pp. 78、80 |
| 多於 n 個 | 必相依 | 同來源 PDF pp. 71–75 |
| 少於 n 個 | 不足以生成 V | 同來源 PDF pp. 82–83 |
| 少於 n 個且獨立 | 可從原 span 外加入向量，擴充成基底 | 同來源 PDF p. 84 |
| 多於 n 個且生成 V | 可移除冗餘向量，縮減成基底 | 同來源 PDF p. 85 |

## 標準例子

- ℝⁿ：標準基底 `{e₁,…,eₙ}`，維度 n。（同來源 PDF p. 86）
- 實數 2×2 矩陣空間：`{E₁₁,E₁₂,E₂₁,E₂₂}`，維度 4。（同來源 PDF pp. 66–67、75）
- 本講義 Pₙ：次數小於 n，基底 `{1,x,…,xⁿ⁻¹}`，維度 n。所有多項式的空間 P 無限維。（同來源 PDF pp. 77、86）
- 零空間例題：`{(1,−2,1,0)ᵀ,(−1,1,0,1)ᵀ}` 生成所有解且獨立，維度 2。（同來源 PDF pp. 68–70、75）

## 適用條件

向量的「個數」只有搭配環境空間與獨立／生成條件才能推出基底；Pₙ 定義也須先核對。相關：[線性獨立與相依](線性獨立與相依.md)、[判定方法選擇](../questions/如何選擇獨立性判定方法.md)。
