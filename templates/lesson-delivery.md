## 交付檢查

- [ ] 原 PDF 已保存且雜湊一致，未覆蓋不同版本。
- [ ] 範圍內每頁均有完整翻譯、詳細講解及頁碼對應，無重要漏譯或跳頁。
- [ ] 講解交代符號、目標、必要步驟與理由及結果意義，未只重述或報結論。
- [ ] 補充只在有助理解當頁時保留，無補充頁不顯示空標題、空卡片或占位文字。
- [ ] 重要公式／圖表／程式核對，補充及勘誤有依據。
- [ ] notes、精簡簡報與逐張講稿齊全，編號及來源一致。
- [ ] 新教材已連入課程 → 章節 → 模式，舊章節仍正常。
- [ ] 自製封面、寬幅原頁、收合目錄、連續獨立捲動及頁碼同步／跳轉可用。
- [ ] 簡報連續換張不跳頂、按鈕位置穩定，全螢幕與鍵盤可用。
- [ ] 筆記／下載／列印及適合的額外形式可用。
- [ ] 桌面、較矮視窗與手機的長文字／公式完整可讀，無裁切、遮擋、難讀縮字、缺圖、斷鏈、橫向溢出或瀏覽器錯誤。
- [ ] Wiki、索引、總覽、日誌與製作狀態已更新。
